# 火柴人战争（网页版）

纯前端单页游戏，打开即玩，手机触屏可直接操作。

- 在线试玩：https://liuyiming2024.github.io/stick-war/
- 本地试玩：双击 `index.html`

## 玩法
- 矿工挖矿产出金币，底部图标栏出兵（7 个兵种）
- 「商店」图标：独立兵种商店页，含价格与兵种定位
- 「升级」图标：独立升级面板，可对每个兵种分别升级 攻击 / 防御 / 攻速（每次 80 金币）
- 我方阵营为绿色、敌方为红色；摧毁对方雕像获胜
- 进攻 / 固守 切换推进节奏

## 素材
`assets/` 内为游戏美术资源（精灵图与战场背景），已统一裁剪、缩放并压缩为 WebP：

| 文件 | 说明 |
| --- | --- |
| `miner/sword/spear/archer/stone/giant/wizard.webp` | 7 个兵种立绘（透明底，高 200px） |
| `statue.webp` | 火柴人石像（透明底，高 320px） |
| `battlefield.webp` | 战场背景（1600×800） |
| `manifest.json` | 各图尺寸与字节数清单 |

原始大图（7.2MB）经裁剪 + LANCZOS 缩放 + WebP 压缩后总量约 150KB。
