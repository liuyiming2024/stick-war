# 火柴人战争 Web

仿《火柴人战争》玩法的单页网页游戏，纯前端、无依赖，打开 index.html 即玩。

## 玩法
- 矿工在本方矿点挖金币，是唯一经济来源
- 商店出兵：矿工 / 剑士 / 矛士 / 弓箭手 / 投石兵 / 巨人 / 巫师
- 升级面板可对每个兵种强化：攻击（+15%/级）、防御（减伤 12%/级）、攻速（冷却 -10%/级）
- 我方为绿色阵营，敌方为红色阵营，摧毁敌方雕像获胜
- 人口上限 20，进攻 / 固守两种阵型切换

## 运行
直接双击 `index.html`，或访问 GitHub Pages 部署地址。

## 技术
Canvas 2D + 原生 JS，单文件自包含，无外部依赖。
